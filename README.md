# Joseph Mod

## Downloading the right version of Baldi's Basics +
1. Go to [SteamDB.info](https://steamdb.info/)
2. Search "Baldi's Basics +"
3. On the left click "Depots"
4. Select what OS you use
5. On the left click "Manifests"
6. At the top of the page you should see a button that says "DepotDownloader" Click it
7. Find the release on the date "30 June 2025 – 11:06:52 UTC" and copy the manifest
8. Make sure you have [DepotDownloader](https://github.com/steamre/depotdownloader) Downloaded
9. Download the manifest Through [DepotDownloader](https://github.com/steamre/depotdownloader) [Heres a tut](https://youtu.be/qPWM6Jr8TUM?si=lRYBJbZvbMB1Xark)

## Importing the Mod
1. Make sure you have [Baldi's Basics + Mod Manager](https://gamebanana.com/tools/20690) Installed
2. Set up the BepInEx with the mod mananger
3. Once done download [JosephIsReal.zip](https://github.com/SillyMonkeyFlip/Baldi-s-Basics-Mod-Archive/tree/main/BB%2B/Joseph%20Is%20Real) and [thinkerapi_release_84efd.zip](https://github.com/SillyMonkeyFlip/Baldi-s-Basics-Mod-Archive/tree/main/BB%2B/ThinkerAPI)
4. Go to your Baldi's Basics + Path and go into BepInEx/Plugins and Extract the mods .Dll's into the folder.
5. Go back to the root folder and navigate to  BALDI_Data/StreamingAssets/Modded and extrat the mods folders into there

You know the mod worked if when you exit the elevator baldi isnt there!
